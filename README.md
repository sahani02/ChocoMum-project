# 🍫 ChocoMum - Online Chocolate Store

Welcome to the **ChocoMum** repository! This is a multi-page web application built using pure **HTML** and **CSS**, designed to showcase an online chocolate store experience.

---

## 🚀 Pages & Features

The project includes the following core pages:

* **Home Page (`Home.html`)**: Features the store branding, an introduction to ChocoMum's chocolate truffles, an embedded video preview, and a navigation menu.

<img width="1920" height="1080" alt="home page" src="https://github.com/user-attachments/assets/02ed91f1-80a7-4842-8ece-435f12175b1f" />

* **Prices Page (`Price.html`)**: Displays a comprehensive product catalog with prices in LKR and product images for items like Cadbury Dairy Milk, KitKat, Galaxy, Toblerone, and Ferrero Rocher.

<img width="1920" height="1080" alt="price page" src="https://github.com/user-attachments/assets/6ce4dc8a-38dd-4f0e-a631-6374a5b3c0b9" />

* **Contact Page (`contact.html`)**: Includes store address details located at 304, Peradeniya Road, Kandy, alongside a contact form with fields for Name, Email, and Message.

<img width="1920" height="1080" alt="contact page" src="https://github.com/user-attachments/assets/bd04c8f4-2979-4dd4-9850-8daca48cf8ce" />

* **Login Page (`login.html`)**: Provides a user authentication interface featuring username and password input fields.

<img width="1920" height="1080" alt="login page" src="https://github.com/user-attachments/assets/af55e37e-fac0-4ce0-b0f2-cffc6c4fd119" />

## 🛠️ Technologies Used

* **HTML5**: Used for structuring the content and layout of all web pages.
* **CSS3**: Used for styling the themes, typography, tables, and form elements.
